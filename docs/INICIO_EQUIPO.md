# Checkpoint inicial no calificado

1. El líder crea el repositorio público e invita al equipo.
2. Todos clonan el mismo repositorio.
3. Cada integrante ejecuta tests y aplicación en su equipo.
4. Cada integrante abre una rama `setup/nombre`, agrega su nombre sin datos personales y crea un PR.
5. Otro integrante revisa el PR con una observación técnica verificable.
6. El equipo registra ambiente, resultado, bloqueo y evidencia individual.

Evidencia mínima: URL del repositorio y PR, commit, salida de tests, aplicación local y explicación breve. La cantidad de commits no es criterio de dominio.
